# Application icon

`palworld-server-operations.png` is the editable high-resolution source for the
Windows application icon. `palworld-server-operations.ico` is generated from it
with `../build-icon.py` and contains the Windows sizes from 16 px through
256 px.

The icon is original project artwork created for Palworld Server Operations with
OpenAI image generation and selected, background-cleaned, and integrated by
the project maintainer. It depicts an original round fantasy companion holding
a small server appliance. It does not reproduce or derive from a Palworld
creature, Pocketpair artwork, or another third-party game mascot.

Do not replace either file with artwork copied from a game, website, or another
project unless its license clearly permits redistribution in this repository.
